# SMP-SMK-SKILLS_PANEL-001

> **Summary:** Работоспособность панели навыков персонажа
>
> **Example:** *Панель навыков открывается/закрывается, иконки уровней интерактивны, уровни повышаются, описания уровней меняются, очки опыта тратятся, максимальное количество очков опыта не превышает порог.*

| Field | Value |
| :--- | :--- |
| **Status** | Пройден |
| **Severity** | Значительный |
| **Priority** | P2 (Средний) |
| **Environment** | ОС: Windows 11 Pro, Устройство: ПК |

## Preconditions
- Билд развернут.
- Тестовый аккаунт доступен.
- На аккаунте имеется больше 1000 очков опыта.
- Если персонаж старик, то больше 1300 очков опыта.

## Steps to Reproduce

| # | Action | Expected Result | Actual Result |
|---| :--- | :--- | :--- |
| 1 | Активировать алтарь аэдра | Проигрывается анимация молитвы, открывается панель навыков персонажа | - |
| 2 | Навести курсор на иконку навыка | Активируется анимация иконки, появляется описание навыка | - |
| 3 | Кликнуть по иконке навыка | Цвет иконки меняется | - |
| 4 | Кликнуть «Изучить» | Навык меняет цвет в зависимости от уровня. Количество опыта в графе «Опыт» уменьшается. Очков памяти становится меньше. | - |
| 5 | Повысить уровни навыков суммарно больше, чем параметр «Память» | Повышение уровня не происходит | - |
| 6 | Кликнуть «Сбросить» | Появляется предупреждение о сбросе навыков | - |
| 7 | Кликнуть «Да» | Навыки сбрасываются. Очки памяти на максимальном значении. Не старик: 1000, Старик: 1300. Очки опыта возвращаются исходя из формула расчета | - |
| 8 | Кликнуть «Выйти» | Панель закрывается, персонаж может перемещаться | - |
